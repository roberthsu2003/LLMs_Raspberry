# 事件發射器

> ⭐ 最簡單，超有感
> 學生會立刻看到「點按鈕→事件立即回傳」的即時反應

```python
"""
title: Copy to Clipboard
author: Your Name
version: 0.1.0
"""

from pydantic import BaseModel
import asyncio

class Action:
    class Valves(BaseModel):
        pass

    def __init__(self):
        self.valves = self.Valves()

    async def action(
        self,
        body: dict,
        __user__=None,
        __event_emitter__=None,
        __event_call__=None,
    ) -> dict:
        """複製 AI 回應到剪貼簿"""
        message_content = body.get("message", "")
        
        if __event_emitter__:
            await __event_emitter__({
                "type": "status",
                "data": {
                    "description": "正在複製到剪貼簿...",
                    "done": False
                }
            })
            
            await asyncio.sleep(0.5)
            
            await __event_emitter__({
                "type": "message",
                "data": {
                    "content": f"✅ 已複製 {len(message_content)} 個字符到剪貼簿"
                }
            })
            
            await __event_emitter__({
                "type": "status",
                "data": {
                    "description": "複製完成！",
                    "done": True
                }
            })
        
        return {"status": "success"}
```

## 📝 詳細語法說明

### 1. **模組匯入**
```python
from pydantic import BaseModel
import asyncio
```
- `BaseModel`：用於定義資料驗證模型（這裡用於 Valves）
- `asyncio`：用於非同步程式設計，包括 `await` 和 `sleep()`

---

### 2. **類別定義**
```python
class Action:
    class Valves(BaseModel):
        pass
```
- `Action`：OpenWebUI 期望的主類別名稱（**不能改**）
- `Valves`：外掛的可配置參數類別（這裡為空，表示無參數）
- 繼承 `BaseModel` 可驗證資料型態

---

### 3. **初始化方法**
```python
def __init__(self):
    self.valves = self.Valves()
```
- `__init__`：建構子，OpenWebUI 初始化外掛時自動呼叫
- `self.valves`：儲存配置參數（若 Valves 有內容，會在這裡初始化）

---

### 4. **非同步 Action 方法（核心）**
```python
async def action(
    self,
    body: dict,
    __user__=None,
    __event_emitter__=None,
    __event_call__=None,
) -> dict:
```

| 參數 | 說明 |
|------|------|
| `self` | 類別實例 |
| `body: dict` | OpenWebUI 傳入的訊息資料，包含使用者輸入 |
| `__user__` | 目前使用者資訊（可選） |
| `__event_emitter__` | **核心參數**，用於發送事件到前端 |
| `__event_call__` | 呼叫其他 Action 的機制（可選） |
| `-> dict` | 返回值型態提示：必須返回字典 |

---

### 5. **提取訊息內容**
```python
message_content = body.get("message", "")
```
- 從 `body` 字典中取得 `"message"` 鍵的值
- 若鍵不存在，預設值為空字串 `""`
- 這是安全的字典存取方式

---

### 6. **條件檢查**
```python
if __event_emitter__:
```
- 檢查 `__event_emitter__` 是否存在
- 防止在沒有事件發射器的環境中執行而出錯

---

### 7. **發送事件：第一個事件（開始狀態）**
```python
await __event_emitter__({
    "type": "status",
    "data": {
        "description": "正在複製到剪貼簿...",
        "done": False
    }
})
```

| 欄位 | 說明 |
|------|------|
| `type: "status"` | 事件類型為「狀態更新」，OpenWebUI 會顯示進度指示器 |
| `description` | 在 UI 中顯示的文字說明 |
| `done: False` | 表示還未完成（進度條狀態） |

---

### 8. **非同步延遲**
```python
await asyncio.sleep(0.5)
```
- `await`：等待異步操作完成（關鍵字）
- `asyncio.sleep(0.5)`：暫停 0.5 秒
- 模擬實際的複製處理時間
- **教學意義**：示範如何在非同步函式中等待

---

### 9. **發送事件：第二個事件（成功訊息）**
```python
await __event_emitter__({
    "type": "message",
    "data": {
        "content": f"✅ 已複製 {len(message_content)} 個字符到剪貼簿"
    }
})
```

| 欄位 | 說明 |
|------|------|
| `type: "message"` | 事件類型為「訊息」，會在聊天歷史中顯示 |
| `content` | 訊息內容，支援 f-string 格式化 |
| `{len(message_content)}` | 計算訊息長度，動態顯示字符數 |

---

### 10. **發送事件：第三個事件（完成狀態）**
```python
await __event_emitter__({
    "type": "status",
    "data": {
        "description": "複製完成！",
        "done": True
    }
})
```
- `done: True`：表示任務已完成
- OpenWebUI 會隱藏或更新進度指示器

---

### 11. **函式返回值**
```python
return {"status": "success"}
```
- 返回字典，告知 OpenWebUI 此 Action 執行成功
- 可選返回值：
  - `{"status": "success"}` ✅ 成功
  - `{"status": "error", "message": "錯誤訊息"}` ❌ 失敗

## 🎓 教學重點（為什麼要教這個程式）

### 核心概念 1：**非同步程式設計（async/await）**
```python
async def action(...):
    await __event_emitter__(...)  # 異步發送事件
    await asyncio.sleep(0.5)      # 異步暫停
```
- 不會阻塞主程式
- 多個任務可以並行執行

### 核心概念 2：**事件驅動架構（Event Emitter）**
```python
if __event_emitter__:
    await __event_emitter__({
        "type": "status",
        "data": {...}
    })
```
- 將資訊實時推送到前端
- 使用者能看到進度變化

### 核心概念 3：**資料流向**
- **輸入**：`body` 字典（使用者資料）
- **處理**：Python 邏輯
- **輸出**：發送多個事件 + 返回狀態
