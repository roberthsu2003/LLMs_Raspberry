# Action 進階教學 3：多格式導出選擇器 (進階整合)

此方案於單一的 Action 互動中，提供排版好的多個下載選項（包含 Word、Excel、JSON），展示強大的介面渲染能力。使用者可以依據自己的需求，選擇最合適的檔案下載。

> 若需了解 Base64 Data URI 下載的核心概念與機制，建議先參考：[進階 Action 教學 1：導出為 Word 檔](./導出為Word檔.md)。

---

## 🎨 完整程式碼

```python
"""
title: 多重格式導出
author: 您的姓名
version: 1.0
description: 支援 Word、Excel、JSON 等多重檔案格式任選下載。
requirements: python-docx, pandas, openpyxl
"""

import json
import base64
from io import BytesIO
from typing import Optional
from datetime import datetime

import pandas as pd
from docx import Document
from fastapi import Request

class Action:
    def __init__(self):
        self.type = "action"
        self.id = "multi_format_export"
        self.name = "💾 多格式導出版"

    async def action(
        self, body: dict, __user__: Optional[dict] = None, __event_emitter__=None
    ) -> Optional[dict]:
        
        messages = body.get("messages", [])
        if not messages:
            return body
        
        last_response = next((msg.get("content", "") for msg in reversed(messages) if msg.get("role") == "assistant"), None)
        timestamp = datetime.now()
        
        # --- 處理 Word (.docx) ---
        doc = Document()
        doc.add_heading("聊天內容備份", level=1)
        doc.add_paragraph(last_response or "無回覆內容")
        word_buf = BytesIO()
        doc.save(word_buf)
        word_buf.seek(0)
        word_b64 = base64.b64encode(word_buf.getvalue()).decode()
        
        # --- 處理 Excel (.xlsx) ---
        df = pd.DataFrame([{"內容": last_response, "時間": timestamp.strftime("%Y-%m-%d %H:%M:%S")}])
        exl_buf = BytesIO()
        with pd.ExcelWriter(exl_buf, engine='openpyxl') as writer:
            df.to_excel(writer, index=False, sheet_name="備份")
        exl_buf.seek(0)
        exl_b64 = base64.b64encode(exl_buf.getvalue()).decode()
        
        # --- 處理 JSON (.json) ---
        json_data = {
            "content": last_response,
            "timestamp": timestamp.isoformat(),
            "operator": __user__.get("name", "Unknown") if __user__ else "Unknown"
        }
        json_b64 = base64.b64encode(json.dumps(json_data, ensure_ascii=False).encode('utf-8')).decode()

        # --- 組合 Markdown 下載點並附加至對話 ---
        md_links = (
            f"**✅ 導出已就緒！請選擇下載格式**：  \n\n"
            f"📘 [Word (.docx)](data:application/vnd.openxmlformats-officedocument.wordprocessingml.document;base64,{word_b64}) | "
            f"📗 [Excel (.xlsx)](data:application/vnd.openxmlformats-officedocument.spreadsheetml.sheet;base64,{exl_b64}) | "
            f"📙 [JSON (.json)](data:application/json;charset=utf-8;base64,{json_b64})\n\n"
            f"*(提示：如果點擊 JSON 後只在網頁顯示內容而沒有下載，請對連結「點選右鍵 ➔ 另存連結」即可成功保存檔案)*"
        )
        
        messages[-1]["content"] += f"\n\n---\n{md_links}"
            
        return body
```

## 💡 開發解析

1. **無依賴推播系統**：如同前兩個範例所述，由於 Open WebUI 前端的 Action 按鈕機制可能會對 `__event_emitter__` 的 SSE 串流解析報錯 (`Unexpected token d in JSON`)，因此最穩定的方式是直接將 HTML 格式的下載超連結附加至聊天內容中，並回傳修改後的 `body` 來更新畫面。
2. **多種 MIME 機制並行**：透過不同的 `data:application/vnd...`，瀏覽器能清晰辨識不同的下載格式，確保副檔名與內部編碼一致。
3. **JSON 導出實用性**：對於常在做流程串接的開發人員，使用 Python 原生的 `json` 函式庫做編碼可以直接產出結構化報表，十分方便。
