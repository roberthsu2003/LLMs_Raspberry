# Filter 範例：在 AI 回答結尾加上「天天開心」

**行為**：模型回覆後，在**最近一次** assistant 訊息的內容末尾加上 `\n\n天天開心`（不修改使用者訊息、不重複加工更早的 assistant 回合）。

```python
"""
title: 在 AI 回答結尾加上「天天開心」
author: open-webui
version: 0.1
"""

from typing import Optional


class Filter:
    def __init__(self):
        pass

    def inlet(self, body: dict, __user__: Optional[dict] = None) -> dict:
        return body

    def outlet(self, body: dict, __user__: Optional[dict] = None) -> dict:
        messages = body.get("messages", [])
        for msg in reversed(messages):
            if msg.get("role") == "assistant":
                text = msg.get("content", "") or ""
                msg["content"] = text + "\n\n天天開心"
                break
        return body
```

## 說明

- **`inlet`**：原樣通過，不做修改。
- **`outlet`**：從對話陣列**尾端往前**找第一則 `role == "assistant"`（即本輪模型輸出），在其 `content` 後接上固定字串。
- 若需要**可調參數**（Valves），可再自行加上 `pydantic` 的 `Valves`／`UserValves` 類別與 `self.valves` 初始化；本範例刻意省略以保持最簡。
