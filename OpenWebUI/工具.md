# Open WebUI 工具（Tools）教學講義

**設定位置**：`工作區 > 工具`

系統性拆解 Open WebUI 工作區裡的**工具**能做什麼.

---

## 結論

Open WebUI 的**工具**，本質是：

> **用一個固定結構的 Python 類別，把「可被 LLM 呼叫的功能」包起來。**

掌握以下 3 點就能開始用：

1. **這不是 Flask / FastAPI** — 不用學傳統後端框架
2. **不用自己處理 http request / http response** — 由 Open WebUI 代勞
3. **只要寫「函式 + 描述 + 型別」** — 專注在邏輯與描述

---

## 一、工作區裡的「工具」是在做什麼？

在 **工作區 → 工具** 裡，你其實是在做三件事：

| 功能     | 白話敘述                         |
|----------|------------------------------------|
| **定義工具** | 告訴 AI：「你有這個能力可以用」     |
| **描述工具** | 告訴 AI：「什麼情況該用它」         |
| **實作工具** | 用 Python 實際做事                  |

> 👉 AI 不一定會用你寫的工具  
> 👉 但「描述寫得好」，AI 才會用

---

## 二、必懂的工具功能類型

### 🟢 Level 1：純計算 / 字串處理

**能力特色**

- 不碰外部系統
- 不碰檔案
- 回傳就是字串或數字

**目標**：理解「AI 可以『決定』要不要呼叫我寫的 Python 函式」。

**適合範例**：單位轉換、日期格式化、字串清洗。

---

### 🟡 Level 2：讀取外部資料

**能力特色**

- 呼叫 API
- 讀 RSS / JSON
- 查即時資訊

**亮點**：「AI 說『我要查資料』 → 工具被呼叫」。

---

### 🔵 Level 3：檔案 / RAG / 系統整合（進階）

**能力特色**

- 讀文件
- 向量搜尋
- 接資料庫

## 三、「一定要會」的 Python 工具結構

> 👉 **這個結構比語法還重要**

### 工具檔案的最小可用骨架

```python
"""
title: 工具名稱
author: 作者名字
version: 1.0
description: 這個工具在做什麼
"""

from pydantic import BaseModel, Field

class Tools:

    class Input(BaseModel):
        text: str = Field(description="使用者輸入的文字")

    def my_tool(self, text: str) -> str:
        """
        將輸入文字轉為大寫
        """
        return text.upper()
```

### 「心智模型化」

| 元素 | 白話說明 |
|------|----------|
| `class Tools` | 工具容器（一定要有） |
| `class Input` | 給 AI 看的參數說明書 |
| `def my_tool` | 真的在做事的地方 |
| **docstring** | 給 AI 判斷要不要用的關鍵 |

## 五、範例題目

### 範例 0：一分鐘懂工具（台灣農民曆 24 節氣）⭐ 先教這個

**一句話**：工具 = 一個 Python 類別，裡面包「可被 AI 呼叫的資料」；當使用者問 24 節氣時，把節氣說明傳給 AI 參考。

**學生在聊天裡說**：「什麼是 24 節氣？」「立春是什麼時候？」「大寒的農諺是什麼？」

**發生的事**：AI 判斷要用你的工具 → 呼叫工具取得 24 節氣資料 → 用這份資料回答學生。

---

#### 完整程式碼

```python
"""
title: 台灣農民曆 24 節氣
author: 教學用
version: 1.0
description: 當使用者問 24 節氣、節氣日期或農諺時，提供台灣農民曆 24 節氣說明給 AI 參考
"""

from pydantic import BaseModel, Field

# 台灣農民曆 24 節氣說明（供 AI 參考）
TERMS_24 = """
【給 AI 的說明：節氣與日期區間】
每個節氣對應一個「日期區間」：若某日落在該區間內，則「目前」就是該節氣。
例如：2月3日～2月18日 代表目前是立春；2月18日～3月5日 是雨水；3月5日～3月20日 是驚蟄；3月20日～4月4日 是春分；4月4日～4月19日 是清明；4月19日～5月5日 是穀雨；5月5日～5月21日 是立夏；5月21日～6月6日 是小滿；6月6日～6月21日 是芒種；6月21日～7月7日 是夏至；7月7日～7月22日 是小暑；7月22日～8月8日 是大暑；8月8日～8月23日 是立秋；8月23日～9月8日 是處暑；9月8日～9月23日 是白露；9月23日～10月8日 是秋分；10月8日～10月24日 是寒露；10月24日～11月8日 是霜降；11月8日～11月22日 是立冬；11月22日～12月7日 是小雪；12月7日～12月22日 是大雪；12月22日～1月5日 是冬至；1月5日～1月20日 是小寒；1月20日～2月3日 是大寒。
（以上為約略日期，每年節氣交節日可能有一兩日差異。）

---

立春（2月3日～4日）:為二十四節氣之首。春天開始。農諺有云：『立春趕春氣』，是因立春之後，萬象回春。此時，開始『春耕、夏耘、秋收、冬藏』的時令季節輪轉。

雨水（2月18～19日）:氣溫回升，降雨的機率增高。農諺：『雨水連綿是豐年』。

驚蟄（3月5～6日）:春雷初響，驚動了蟄伏的冬眠動物開始活動。農諺：「過了驚蟄節，春耕不停歇」。

春分（3月20～21日）:春天過了一半，白晝與黑夜各為十二小時。農諺：『春分，日暝對分』。

清明（4月4～5日）:天氣轉暖，花草樹木開始萌發枝芽，萬物開始生長。農諺：『清明風若從南起，預報田禾大有收』。

穀雨（4月19～20日）:是春季的最後一個節氣，雨水增多。農諺：「穀雨補老母」。

立夏（5月5～6日）:夏季開始。農諺：「立夏補老爸」。

小滿（5月21日）:稻麥結實成穗亦進入梅雨季節。農諺：「小滿雨水相趕」。

芒種（6月6日）:進入典型的夏季，芒作物開始成熟。農諺：「芒種蝶仔討無食」。

夏至（6月21日）:炎熱夏天來臨，晝長夜短。農諺：「夏至風颱就出世」。

小暑（7月7日）:天氣一天比一天熱，農諺：「小暑過，一日熱三分」。

大暑（7月22～23日）:一年天氣最炎熱的時候，俗諺：「大暑曝死老鼠」。

立秋（8月8日）:秋天伊始，立秋時氣溫慢慢下降但天氣仍炎熱，俗諺：「立秋煎鰗鰍」。

處暑（8月23日）:暑氣將要結束，白天熱，早晚涼，晝夜溫差大，降水少，空氣濕度低。俗諺：「處暑出大日，秋旱曝死鯽」。

白露（9月8日）:夜間氣溫下降較快而致水氣開始凝結成露水，露水晶瑩剔透，呈白色而得名。俗諺：「白露勿露身，早晚要叮嚀」。

秋分（9月23日）:秋天過半，晝夜等長。俗諺：「秋分暝日對分」。

寒露（10月8日）:寒露代表深秋來臨。天氣比白露更冷。

霜降（10月24日）:天氣變得更冷，地面結霜。但是台灣平地實際上極少結霜。

立冬（11月8日）:是冬天的第一個節氣，標示著冬天的開始。

小雪（11月22日）:中國地區北部開始下雪，但雪量不大，故名小雪。而地處亞熱帶的台灣只有山上才有可能下雪。

大雪（12月7日）:雪量增加，名大雪。

冬至（12月22日）:本日晝最短夜最長。俗諺：「冬至烏，過年酥」。

小寒（1月5日）:冬至過後天氣漸寒，尚未大冷，故名小寒。俗諺：「小寒大寒人馬安」。

大寒（1月20日）:一年中最冷的時間，也是24節氣的最後一個節氣。俗諺：「大寒冬已盡，寒極春漸至」。
"""

class Tools:

    class Input(BaseModel):
        query: str = Field(default="", description="想查的節氣名稱，例如：立春、雨水。留空則回傳全部 24 節氣說明。")

    def get_24_terms(self, query: str = "") -> str:
        """回傳台灣農民曆 24 節氣說明，供 AI 回答使用者關於節氣、農諺、日期的問題。若傳入節氣名稱則只回傳該節氣段落。"""
        text = TERMS_24.strip()
        if not query or query.strip() == "":
            return text
        # 依關鍵字篩選：找出包含該節氣名稱的段落
        keyword = query.strip()
        for block in text.split("\n\n"):
            if keyword in block:
                return block
        return text
```

#### 給 AI 的說明：日期區間 = 目前節氣

工具回傳的開頭有一段 **【給 AI 的說明：節氣與日期區間】**，專門給 AI 解讀用：

- **規則**：某日落在某個「日期區間」內，就代表**目前是那個節氣**。
- **例如**：**2月3日～2月18日 代表目前是立春**；2月18日～3月5日是雨水，依此類推。
- 這樣當使用者問「今天是什麼節氣？」或「現在是立春嗎？」時，AI 就能依當日日期判斷並回答。

---

#### 三個重點（講給學生聽）

| 重點 | 說明 |
|------|------|
| **1. class Tools** | 固定寫法，Open WebUI 只認這個名字 |
| **2. TERMS_24** | 把「要給 AI 參考的資料」放在變數裡，工具只負責回傳 |
| **3. get_24_terms** | 被呼叫時回傳 24 節氣全文；若傳入節氣名稱則只回傳該段，讓 AI 回答更精準 |

> 👉 **工具裡沒有 AI**，只是回傳資料。AI 負責「決定要不要用」跟「用這份資料回答使用者」。

---

#### 為什麼先教這個？

- **資料在程式裡**：不碰網路、不碰檔案，結構一眼就懂
- **description 寫清楚**：AI 才知道「使用者問 24 節氣時」要呼叫這個工具
- 學生馬上能體會：「我寫的 Python 被 AI 呼叫了，而且 AI 用我的資料回答」

教完這個再教單位換算、API 會比較順。

### 範例 1：BMI 計算（身體質量指數）⭐ Level 1 進階

**一句話**：工具接收兩個數值（身高、體重），計算 BMI 並判斷健康狀態。

**學生在聊天裡說**：「我身高 170 公分、體重 65 公斤，BMI 是多少？」或「幫我算 BMI，身高 155 體重 52」

**發生的事**：AI 判斷要用你的工具 → 傳入身高 `170`（公分）、體重 `65`（公斤）→ 函式計算 `65 / 1.70² = 22.5` → 判斷為「正常範圍」→ 回給學生「BMI = 22.5，屬於正常範圍」。

---

#### 完整程式碼

```python
"""
title: BMI 計算（身體質量指數）
author: 教學用
version: 1.0
description: 根據身高和體重計算 BMI（身體質量指數），並判斷健康狀態。公式：BMI = 體重(公斤) / 身高²(公尺²)
"""

from pydantic import BaseModel, Field

class Tools:

    class Input(BaseModel):
        height_cm: float = Field(description="身高（公分）")
        weight_kg: float = Field(description="體重（公斤）")

    def calculate_bmi(self, height_cm: float, weight_kg: float) -> str:
        """
        計算 BMI 並判斷健康狀態。
        公式：BMI = 體重(公斤) / 身高²(公尺²)
        分級：
        - 體重過輕：BMI < 18.5
        - 正常範圍：18.5 ≤ BMI < 24
        - 過重：24 ≤ BMI < 27
        - 輕度肥胖：27 ≤ BMI < 30
        - 中度肥胖：30 ≤ BMI < 35
        - 重度肥胖：BMI ≥ 35
        """
        # 將公分轉換為公尺
        height_m = height_cm / 100
        # 計算 BMI
        bmi = weight_kg / (height_m ** 2)
        
        # 判斷健康狀態
        if bmi < 18.5:
            status = "體重過輕"
        elif bmi < 24:
            status = "正常範圍"
        elif bmi < 27:
            status = "過重"
        elif bmi < 30:
            status = "輕度肥胖"
        elif bmi < 35:
            status = "中度肥胖"
        else:
            status = "重度肥胖"
        
        return f"BMI = {bmi:.1f}，屬於「{status}」"
```

---

#### 三個重點（講給學生聽）

| 重點 | 說明 |
|------|------|
| **1. 多個參數** | `height_cm` 和 `weight_kg` 兩個 `float` 參數，讓 AI 知道要傳兩個數字 |
| **2. 公式與判斷** | BMI 計算和健康狀態判斷都寫在函式裡，AI 不用自己算 |
| **3. 回傳字串** | 用 `f-string` 和 `:.1f` 格式化，回傳人類好讀的結果，例如 `BMI = 22.5，屬於「正常範圍」` |

> 👉 **範例 0 是資料查詢、範例 1 是計算+判斷** — 讓學生體會「多個參數、多層邏輯」，結構一樣。

---

#### 為什麼教這個？

- 仍是 **Level 1**（不碰網路、不碰檔案）
- **兩個參數**：練習 `Input` 裡定義多個欄位
- **條件判斷**：用 `if-elif-else` 做健康狀態分級，邏輯更豐富
- 學生能問「我身高 170、體重 65，BMI 多少？」馬上得到答案和健康建議，實用性高
