# Open WebUI 工具（Tools）教學講義

**設定位置**：`工作區 > 工具`

本講義以「教學生好上手」為目標，系統性拆解 Open WebUI 工作區裡的**工具**能做什麼，以及學生最容易理解、最有成就感的 Python 工具範例結構。

---

## 一句話：教學定位結論

Open WebUI 的**工具**，本質是：

> **用一個固定結構的 Python 類別，把「可被 LLM 呼叫的功能」包起來。**

學生只要掌握以下 3 點就能開始用：

1. **這不是 Flask / FastAPI** — 不用學傳統後端框架
2. **不用自己處理 request / response** — 由 Open WebUI 代勞
3. **只要寫「函式 + 描述 + 型別」** — 專注在邏輯與描述

---

## 一、工作區裡的「工具」是在做什麼？

在 **工作區 → 工具** 裡，你其實是在做三件事：

| 功能     | 教學用白話                         |
|----------|------------------------------------|
| **定義工具** | 告訴 AI：「你有這個能力可以用」     |
| **描述工具** | 告訴 AI：「什麼情況該用它」         |
| **實作工具** | 用 Python 實際做事                  |

> 👉 AI 不一定會用你寫的工具  
> 👉 但「描述寫得好」，AI 才會用

---

## 二、學生必懂的工具功能類型（教學分級）

### 🟢 Level 1：純計算 / 字串處理（最適合第一堂）

**能力特色**

- 不碰外部系統
- 不碰檔案
- 回傳就是字串或數字

**教學目標**：讓學生理解「AI 可以『決定』要不要呼叫我寫的 Python 函式」。

**適合範例**：單位轉換、日期格式化、字串清洗。

---

### 🟡 Level 2：讀取外部資料（學生開始有感）

**能力特色**

- 呼叫 API
- 讀 RSS / JSON
- 查即時資訊

**教學亮點**：學生第一次看到「AI 說『我要查資料』 → 工具被呼叫」。

---

### 🔵 Level 3：檔案 / RAG / 系統整合（進階）

**能力特色**

- 讀文件
- 向量搜尋
- 接資料庫

這一層很適合後續銜接：**RAG**、**Agent**、**Tool chaining**。

---

## 三、學生「一定要會」的 Python 工具結構

> 👉 **這個結構比語法還重要**

### 工具檔案的最小可用骨架

```python
"""
title: 工具名稱
author: 教師或學生名字
version: 1.0
description: 這個工具在做什麼
"""

from pydantic import BaseModel, Field

class Tools:

    class Input(BaseModel):
        text: str = Field(description="使用者輸入的文字")

    def my_tool(self, text: str) -> str:
        """
        將輸入文字轉為大寫
        """
        return text.upper()
```

### 教學生怎麼「心智模型化」

你可以直接這樣說：

| 元素 | 白話說明 |
|------|----------|
| `class Tools` | 工具容器（一定要有） |
| `class Input` | 給 AI 看的參數說明書 |
| `def my_tool` | 真的在做事的地方 |
| **docstring** | 給 AI 判斷要不要用的關鍵 |

## 四、為什麼 Open WebUI 的工具特別適合教學？

### 和傳統後端教學的差別

| 項目       | 傳統 Python API | Open WebUI 工具 |
|------------|-----------------|------------------|
| 學 HTTP    | ❌ 要           | ✅ 不用          |
| 學框架     | ❌ 要           | ✅ 不用          |
| 學部署     | ❌ 要           | ✅ 不用          |
| 專注邏輯   | 常被環境分散    | ✅ 可專注        |
| 立即看到 AI 使用 | ❌ 難           | ✅ 第一堂就能成功 |

> 👉 學生不會被「環境」打敗  
> 👉 第一堂就能有成就感

## 五、三個「學生秒懂」的教學範例題目（推薦）

### 範例 1：文字處理工具（第一堂）

**情境**：「幫我把這段文字轉成適合簡報用的句子」

- AI 自動呼叫工具
- 學生第一次看到工具被使用

---

### 範例 2：RSS / API 工具（第二～三堂）

**情境**：「今天有沒有和 AI 有關的新聞？」

- 工具負責抓資料
- AI 負責解讀

---

### 範例 3：RAG 工具（後段課程）

**情境**：「根據這份文件回答問題」

- 工具查
- AI 說

---

## 六、課程節奏建議（給老師用）

**3 堂課就能讓學生有 Agent 感覺**

1. **第 1 堂**：工具 = 一個函式
2. **第 2 堂**：工具 = AI 可選擇的能力
3. **第 3 堂**：多個工具 = AI 自行決策流程
