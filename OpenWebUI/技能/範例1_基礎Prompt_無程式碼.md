# 範例一：基礎 Prompt Skill（免寫程式碼）

這是一個最淺顯易懂的範例。在 OpenWebUI 中，大部分的「Skill（技能）」其實就是事先寫好的一段 **System Prompt (系統提示詞)**。
您可以透過這段固定的指令，限定 AI 的行為模式，打造出一個專屬的小幫手。

## 🎯 應用場景：專屬商務英文校稿助理

很多時候我們寫出來的英文 Email 雖然文法沒錯，但語氣不夠精準或是不夠專業。
我們可以建立一個專屬的 Skill，只要開啟它，AI 就會自動把它收到的任何內容，改寫成專業的商務英文。

---

## 🛠️ 實作步驟

1. 登入 OpenWebUI，在左側邊欄點選 **Workspace (工作區) → Prompts 或 Skills**。
2. 點選 **+ New (新增)** 建立一個新的 Skill。
3. 依照下方範例設定：

### 📝 填寫內容設定欄位

*   **Title/Name (名稱)**: `商務英文校稿助理`
*   **Command (指令快捷鍵)**: `business-english` 
    *(讓您可以直接在對話框輸入 `/business-english` 快速呼叫它)*
*   **Description (簡單描述)**: `將輸入的內容自動潤飾並翻譯為專業的商務英文 Email。`
*   **Content (主要提示詞內容)**: 請複製以下內容貼上：

```markdown
你現在是一位擁有 20 年跨國外商經驗的資深溝通主管。
接下來，我會給你一段草稿（可能是中文或其他語言），請你直接完成以下兩步：

1. 先點出這段文字在語氣上可以改進的地方（用繁體中文，限 3 句話以內）。
2. 提供一段語氣專業、不卑不亢的「正式 Business Email」英文改寫版本。

請直接開始，不要回覆「好的」或「沒問題」。
```

## 🚀 測試與使用方法

1. 按下儲存 (Save)。
2. 回到首頁建立一個新的對話視窗。
3. 在輸入框打字時，輸入 `/business-english`（或者在使用模型時直接套用這個 Prompt）。
4. 接著輸入：「我明天沒空開會，要改成下週三下午兩點，大家可以嗎？」
5. 你會看到 AI 立刻化身外商主管，幫你用超級專業的語氣精準地產出商務信件！
